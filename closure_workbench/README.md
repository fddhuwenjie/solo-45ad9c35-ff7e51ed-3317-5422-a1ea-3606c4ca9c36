# 盾构推进测量闭合工作台

把**盾构导向点、管片姿态、人工复测**三类来自不同坐标系的测量值，在统一基准版本
（BASE，施工控制网）下闭合：按坐标系统版本转换、构建换站连接拓扑、用里程方向与环号
约束求唯一接续路径；发现阻断冲突时停止闭合并高亮**最小冲突边**；调边权即时重算全线
残差；确认版本时冻结旧坐标、变换参数与可重放计算摘要。

纯 Python 标准库 + SQLite + 原生 HTML/CSS/JS，无第三方依赖、无构建步骤。

## 运行

```bash
python3 server.py          # 默认 http://localhost:8080，首次启动自动播种演示数据
python3 server.py 9000     # 指定端口
CLOSURE_DB=/path/x.db python3 server.py
```

页面标签页：阻断冲突 / 换站拓扑 / 坐标版本 / 全线残差 / 观测数据 / 导入 / 确认与快照。

## 演示数据的三个内置阻断（可在界面逐一解除）

合成 120 环隧道（设计轴 +X、环宽 1.5 m），测站 S0→S1→S2→S3 三次换站：

1. **控制点矛盾环**：复测边 `S0→CP2`（#169）含 18 mm 粗差，使所有经过该 CP 的
   测站—控制点二分图环闭合差超 10 mm 限差；算法高亮最小冲突边 **#169**
   （在「观测数据」勾选忽略即可消除）。
2. **坐标版本同环交叉**：新导向帧 `G2` 未确认时，换站交界第 60 环同时存在 F1/G1 与
   F2/G2 两族观测且无确认变换链；在「坐标版本」对 G2 点确认（控制点配准，RMS≈0.3 mm）
   后解除，管片帧 SG2 随之经 G2 链接入基准。
3. **复测早于换站**：边 `S2→CP2`（#178）时刻早于 S2 的换站时刻，该边不能作为接续
   证据，唯一接续路径因此断裂；把时刻改到换站之后即恢复。

三项全部解除后：`blocked=false`、接续路径 `S0 → S1 → S2 → S3` 唯一、全线平差
RMS ≈ 0.7 mm。可用工具栏「重置为演示数据」随时还原。

## 领域模型与算法

### 统一观测模型（`observations` 表）
- `guide/segment`：某坐标版本 `version_id` 下环点或控制点的**绝对坐标** (x,y)。
- `resurvey`：测站 `station` → 控制点 `target_cp` 的**矢量** (vx,vy)。
- 每条观测带 `content_hash`（对“测量内容”做稳定哈希，**刻意不含权**）。重复导入：
  内容一致→忽略；仅权不同→更新原行，观测数永不增加。

### 坐标版本与相似变换
- 2D 相似变换 `X=a x−b y+t_x, Y=b x+a y+t_y`：
  绝对坐标配准解全部 4 参数（`fit_full`，最少 2 公共点）；纯矢量配准只解
  旋转+尺度 (a,b)（`fit_linear`，平移不可观测）。
- 已确认变换构成无向图，自 BASE 做 BFS 复合出每个版本到基准的链；矢量按线性部分
  转换。确认有 RMS 门限（20 mm），超差拒绝且不写任何参数。
- 同一测期的导向/管片帧归入同一**坐标族**（family），同族同环共存不算交叉；只有
  不同族在同一环且某族未链接基准时才报版本交叉。

### 换站拓扑与唯一接续
- 复测矢量构成 测站(S)—控制点(P) 二分图；两测站共测一个 CP 即产生一条候选接续链接。
- **成对证据隔离**：三个及以上测站共用同一 CP 时，每条接续链接只校验该测站对
  **自身**的复测证据——其它测站在该 CP 上的观测既不能证实也不能证伪这一对；
  每个测站只要有一条不早于其换站时刻的复测即可作为有效证据，个别早期边单独报
  `time_inversion`，不会连带否决同 CP 上的其它测站对。
- 按**里程顺序**（`station_moves` 声明的交出→接管方向）定向，并用**环号约束**过滤
  （接管侧最小环 ≥ 交出侧最大环，否则为环号倒灌）；复测时刻早于换站的边标记为
  早期证据，不参与合法接续。
- 在合法链接上做简单路径枚举，站序列去重：0 条（断链）/1 条（唯一接续）/>1 条
  （约束不足有歧义）都是显式结论。存在阻断项时即使拓扑上唯一，也会在路径结论中
  明确标注“需先解除方可闭合”。

### 阻断即停止平差
任一时间倒置、坐标版本交叉或控制点矛盾环出现（或接续不唯一/断链），`assemble`
立即停止 `line_adjustment`：返回 `adjustment.status="blocked"`，**不产生** RMS、
最大残差、环坐标或逐条残差（均为 `null`/空），API 与页面都不会把它们显示为可用
结果；只有全部阻断解除后才输出 `status="ok"` 的全线平差。

### 阻断冲突（任一存在即停止闭合）
| 类型 | 判定 | 最小冲突边（随冲突逐条返回） |
|---|---|---|
| `contradiction_cycle` | 二分图简单环（Johnson 式枚举）闭合差 > 10 mm | 全局最小反馈边集：逐边试删，选消除坏环最多、误伤好环最少、权最低者；每个环标注重叠的割边 |
| `version_cross` | 同环出现不同坐标族且某族无确认变换链 | 交界环上属于未确认族的观测 |
| `time_inversion` | 复测时刻早于该站换站时刻 | 该早期复测边本身 |
| `ring_inversion` | 声明接续上环号倒灌 | 接管侧环号最小（倒灌）的观测 |

顶层 `topology.cut_edges` 是各冲突最小冲突边的去重并集，供页面统一高亮；阻断态
快照同样只记录 `status=blocked` 与割边，不写平差数值。

### 全线加权最小二乘（调权即时传播）
未知量为每环 (X_i,Y_i)；每条可转换的导向/管片观测加权 w，相邻环加“过程边”
（设计轴步进 1.5 m、权 `process_weight`），首环锚定，整体组成法方程高斯消元求解；
输出每条观测的 dx/dy/残差与全线 RMS。拖动过程边权或改任一边权即触发重算，
残差沿环链重新分布。

### 确认留痕与可重放摘要
- `confirmations`：确认版本时冻结**该版本下全部旧坐标**、拟合参数、参与点摘要、
  输入哈希；旧坐标永久保留，可与后续再确认比对。
- `runs`：一次计算的 `(输入哈希, 参数)` 唯一；同输入同参数不重复落库，快照内含
  原始观测、全部变换参数、确认记录与计算结果（冲突/割边/平差摘要），日后可用相同
  输入重放核对。

## 文件

| 文件 | 作用 |
|---|---|
| `db.py` | SQLite schema、连接、内容哈希/摘要 |
| `engine.py` | 相似变换、版本链、拓扑、冲突检测、最小割、最小二乘、总装 `assemble()` |
| `seed.py` | 合成演示数据（确定性噪声；重复执行幂等） |
| `server.py` | stdlib HTTP 服务与全部 API |
| `test_closure.py` | 回归测试：三站共点成对隔离、三类阻断分别/同时触发、阻断即停平差、割边一致性 |
| `web/` | 原生 `index.html` / `app.css` / `app.js` |

回归测试：

```bash
python3 -m unittest test_closure -v
```

## 主要 HTTP API

```
GET  /api/state?pw=10                # 闭合总装（过程边权可调）
POST /api/observations               # 幂等导入（单对象或数组）
PATCH /api/observations/{id}         # {weight|ignored|measured_at}
POST /api/versions/{id}/confirm      # {to_version, mode: cp_abs|vector|ring}
POST /api/runs                       # 冻结可重放快照（同输入+同参数去重）
GET  /api/runs                       # 快照列表（含冻结旧坐标与参数）
POST /api/reseed                     # 重置演示数据
```
